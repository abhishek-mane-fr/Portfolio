# Abhishek Mane — Shopify Developer Portfolio

A responsive personal portfolio focused on Shopify development, custom Liquid work, eCommerce storefronts and client projects.

## Current setup

- Static HTML/CSS/JavaScript
- Responsive design
- Professional profile photo included
- Project video placeholders ready to be replaced
- Live project links included
- LinkedIn included
- GitHub placeholder included

## Replace before publishing

1. Replace `GITHUB_URL_HERE` in `index.html` with the GitHub profile/repository URL.
2. Replace each `.video-placeholder` block with the final project walkthrough video.
3. Optionally add a downloadable resume.
4. Review project wording and links before publishing.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.
